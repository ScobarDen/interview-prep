C++: основы и ООП 17

Назовите принципы ООП.часто

Инкапсуляция — данные и методы вместе, внутреннее состояние скрыто за интерфейсом. Наследование — класс получает поля и методы базового. Полиморфизм — один интерфейс, разные реализации: вызов через указатель на базовый класс выполняет метод реального типа объекта. Часто добавляют абстракцию — выделение существенного и скрытие деталей.

Чем struct отличается от class?часто

Только доступом по умолчанию: в struct члены и наследование открытые (public), в class закрытые (private). По соглашению struct берут для простых наборов данных без инвариантов.

Что такое виртуальная функция и как она работает?часто

Метод, помеченный virtual, вызывается по реальному типу объекта, а не по типу указателя. Реализация: у каждого класса с виртуальными методами есть таблица виртуальных функций (vtable), а в каждом объекте — скрытый указатель на неё. Вызов идёт через эту таблицу, цена — одно лишнее обращение к памяти.

Зачем нужен виртуальный деструктор?часто

Чтобы при delete через указатель на базовый класс вызвался деструктор наследника. Без него это неопределённое поведение, на практике ресурсы наследника утекают. Правило: есть хотя бы одна виртуальная функция — деструктор тоже виртуальный.

Что такое чисто виртуальная функция и абстрактный класс?часто

Чисто виртуальная функция объявлена с = 0 и не обязана иметь реализацию. Класс хотя бы с одной такой функцией абстрактный: его объект создать нельзя, можно только наследоваться. Так в C++ делают интерфейсы.

Можно ли вызывать виртуальную функцию в конструкторе?

Можно, но полиморфизма не будет: вызовется версия того класса, чей конструктор выполняется, потому что часть наследника ещё не создана. Вызов чисто виртуальной функции так приведёт к падению.

Чем указатель отличается от ссылки?часто

Указатель — переменная с адресом: может быть nullptr, его можно перенаправить, есть арифметика указателей. Ссылка — второе имя существующего объекта: не бывает пустой, привязывается один раз при создании. Ссылку берут для обязательных параметров, указатель — когда «объекта может не быть».

Для чего используется const?часто

Обещание не менять, которое проверяет компилятор. const int x — константа. const T& — параметр без копии и без права менять. Метод с const в конце не меняет объект, и только такие методы можно вызывать у константного объекта. const T* p — нельзя менять объект, T* const p — нельзя менять сам указатель.

Что такое static?

Три значения. Статическое поле или метод класса принадлежит классу, а не объекту. Статическая локальная переменная создаётся один раз и живёт до конца программы. static у глобальной функции или переменной ограничивает её видимость одним файлом.

Как передавать аргументы в функцию?часто

По значению — копия, для маленьких типов (int, double). По константной ссылке const T& — без копии и без изменения, стандарт для больших объектов. По ссылке T& — функция меняет объект вызывающего. По rvalue-ссылке T&& — функция забирает ресурсы временного объекта.

Что такое перегрузка и переопределение?

Перегрузка (overload) — несколько функций с одним именем и разными параметрами, выбор при компиляции. Переопределение (override) — наследник заменяет виртуальный метод базового класса, выбор при выполнении. Слово override просит компилятор проверить, что метод действительно что-то переопределяет.

Какие бывают модификаторы доступа и что такое friend?

public — доступно всем, protected — классу и наследникам, private — только классу. friend даёт конкретной функции или классу доступ к закрытым членам; используют редко, например для оператора <<.

Какие приведения типов есть в C++?часто

static_cast — обычные преобразования, проверяются при компиляции. dynamic_cast — безопасное приведение вниз по иерархии с проверкой при выполнении, возвращает nullptr при неудаче. const_cast — снять const. reinterpret_cast — трактовать биты как другой тип, самое опасное. Приведение в стиле C (T)x не используют: оно молча выбирает любое из них.

Что такое пространство имён и почему не пишут using namespace std в заголовках?

Пространство имён группирует имена и убирает конфликты. using namespace в заголовке втягивает все имена во все файлы, которые его подключают, и ломает чужой код неожиданными совпадениями.

Чем объявление отличается от определения? Зачем нужны заголовочные файлы?

Объявление сообщает компилятору, что сущность существует (void f();). Определение даёт тело или выделяет память. Заголовок содержит объявления, чтобы другие файлы могли использовать код, а определения лежат в .cpp. От повторного включения защищают #pragma once или include guard.

Что такое неопределённое поведение? Приведи примеры.

Ситуация, для которой стандарт не задаёт результата: программа может упасть, выдать мусор или «работать». Примеры: выход за границу массива, разыменование нулевого или висячего указателя, чтение неинициализированной переменной, переполнение знакового целого, двойной delete.

Что такое исключения и как с ними работать?

Механизм сообщения об ошибке: throw бросает, try/catch ловит. При раскрутке стека вызываются деструкторы всех локальных объектов, поэтому RAII делает код безопасным. Ловят по константной ссылке: catch (const std::exception& e). Из деструктора исключения не бросают.

C++: память и указатели 14

Чем стек отличается от кучи?часто

Стек — память под локальные переменные: выделяется и освобождается автоматически при входе в функцию и выходе, очень быстро, размер ограничен (обычно 1–8 МБ). Куча — динамическая память: выделяется через new или контейнеры, живёт, пока её не освободят, медленнее и может фрагментироваться.

Что такое RAII?часто

Идиома: ресурс захватывается в конструкторе объекта и освобождается в его деструкторе. Деструктор вызывается автоматически при выходе из блока, включая выход по исключению, поэтому забыть освобождение невозможно. Примеры: умные указатели, std::lock_guard, std::fstream.

Какие умные указатели есть и чем отличаются?часто

unique_ptr — один владелец, копировать нельзя, можно переместить, накладных расходов нет. shared_ptr — несколько владельцев, счётчик ссылок, объект удаляется с последним. weak_ptr — наблюдатель за объектом shared_ptr, на счётчик не влияет, перед использованием превращается в shared_ptr через lock().

Зачем нужен weak_ptr?часто

Разрывать циклические ссылки: если два объекта держат друг друга через shared_ptr, счётчики не обнулятся и память утечёт. Одну из ссылок делают слабой. Второе применение — кэш и наблюдатели: ссылка, которая не продлевает жизнь объекта.

Как устроен shared_ptr внутри?

Два указателя: на объект и на блок управления. В блоке — счётчик владельцев и счётчик слабых ссылок, оба атомарные. Копирование увеличивает счётчик, деструктор уменьшает и при нуле удаляет объект. Счётчик потокобезопасен, сам объект — нет.

Почему make_shared и make_unique лучше new?

make_shared выделяет объект и блок управления одним куском памяти вместо двух. Оба не дают утечки, если между new и созданием умного указателя вылетит исключение, и убирают слово new из кода.

Что такое утечка памяти, висячий указатель и двойное освобождение?часто

Утечка — память выделили и не освободили. Висячий указатель указывает на уже освобождённую память. Двойное освобождение — delete дважды для одного адреса. Последние два дают неопределённое поведение. Лечатся RAII и умными указателями, ищутся инструментами valgrind и AddressSanitizer.

Чем new отличается от malloc?часто

new выделяет память и вызывает конструктор, возвращает указатель нужного типа, при нехватке памяти бросает std::bad_alloc. malloc только выделяет байты, возвращает void* и NULL при ошибке. Парные операции — delete и free, смешивать нельзя.

Чем delete отличается от delete[]?часто

delete — для одного объекта, delete[] — для массива, выделенного через new[]: он вызывает деструкторы всех элементов. Перепутать — неопределённое поведение.

Что такое lvalue и rvalue?

Упрощённо: lvalue — то, у чего есть имя и адрес, оно живёт дольше одного выражения. rvalue — временное значение: результат a + b, возврат функции по значению. Ссылка T&& привязывается к rvalue, и это позволяет «обобрать» объект, который всё равно сейчас исчезнет.

Что делает std::move?часто

Сам ничего не перемещает: это приведение к rvalue-ссылке, пометка «объект можно обобрать». Перемещение выполняет конструктор или оператор присваивания перемещения. После перемещения объект остаётся в корректном, но неопределённом состоянии: его можно только присвоить заново или уничтожить.

Сколько памяти занимает структура? Что такое выравнивание?

Не сумму размеров полей: компилятор вставляет пустые байты, чтобы каждое поле лежало по адресу, кратному его размеру. struct { char a; int b; char c; } займёт 12 байт, а не 6. Если упорядочить поля от больших к маленьким, размер уменьшится. Пустой класс занимает 1 байт.

Что такое nullptr и чем он лучше NULL?

Литерал нулевого указателя со своим типом std::nullptr_t. NULL — это целое число 0, и при перегрузке f(int) и f(char*) вызов f(NULL) выберет f(int).

Какие области памяти есть у программы?

Код (инструкции, только чтение), сегмент данных (глобальные и статические переменные), стек (локальные переменные и адреса возврата, свой у каждого потока), куча (динамическая память).

C++: конструкторы, копирование, перемещение 11

Какие конструкторы бывают?часто

По умолчанию (без аргументов), с параметрами, копирования T(const T&), перемещения T(T&&). Ещё делегирующий (вызывает другой конструктор того же класса) и преобразующий (с одним аргументом, без explicit).

Какие функции компилятор генерирует сам?часто

Шесть специальных: конструктор по умолчанию, деструктор, копирующие конструктор и присваивание, перемещающие конструктор и присваивание. Объявил свой конструктор — конструктор по умолчанию не генерируется. Объявил деструктор или копирование — не генерируется перемещение.

Что такое правило трёх, пяти и нуля?часто

Трёх: нужен свой деструктор, конструктор копирования или копирующее присваивание — нужны все три. Пяти: то же плюс две операции перемещения. Нуля: лучше хранить ресурсы в полях, которые управляют ими сами (vector, string, умные указатели), и не писать ни одной.

Чем поверхностное копирование отличается от глубокого?часто

Поверхностное копирует поля как есть: для указателя копируется адрес, и два объекта владеют одной памятью. Глубокое выделяет новую память и копирует содержимое. Сгенерированный конструктор копирования для сырого указателя делает поверхностную копию, отсюда двойное освобождение.

Чем T b = a; отличается от b = a;?часто

Первое создаёт новый объект — вызывается конструктор копирования. Второе работает с существующим — вызывается оператор присваивания.

Зачем нужен список инициализации в конструкторе?

Поля создаются сразу с нужным значением, без промежуточного пустого состояния. Обязателен для const-полей, ссылок и полей без конструктора по умолчанию. Порядок инициализации — как поля объявлены в классе, а не как записаны в списке.

Что делает explicit?часто

Запрещает использовать конструктор для неявного преобразования типа. Без него void f(Buffer); f(1024); молча создаст Buffer из числа.

Как запретить копирование объекта?часто

Объявить конструктор копирования и копирующее присваивание с = delete. До C++11 их объявляли в закрытой секции без реализации.

В каком порядке вызываются конструкторы и деструкторы при наследовании?

Конструкторы: базовый класс, затем поля в порядке объявления, затем тело конструктора наследника. Деструкторы — строго в обратном порядке.

Что такое copy elision и RVO?

Оптимизация: при возврате объекта из функции по значению он создаётся сразу в месте назначения, без копирования и перемещения. С C++17 для возврата временного объекта это гарантировано. Поэтому большие объекты спокойно возвращают по значению.

Что будет, если конструктор бросит исключение?

Объект считается несозданным, его деструктор не вызовется. Но деструкторы уже созданных полей и базовых классов вызовутся. Поэтому сырые ресурсы в конструкторе опасны, а поля-RAII безопасны.

C++: STL и шаблоны 15

Какие контейнеры STL вы знаете?часто

Последовательные: vector, deque, list, array. Ассоциативные упорядоченные: map, set (красно-чёрное дерево). Неупорядоченные: unordered_map, unordered_set (хэш-таблица). Адаптеры: stack, queue, priority_queue.

Как устроен vector и что происходит при push_back?часто

Динамический массив в сплошном куске памяти. Есть размер (size) и вместимость (capacity). Когда место кончается, выделяется новый блок в 1,5–2 раза больше, элементы переносятся, старый освобождается. Поэтому push_back — O(1) в среднем (амортизированно), а все итераторы и ссылки после перевыделения недействительны.

Чем vector отличается от list?часто

vector — сплошная память: доступ по индексу O(1), вставка в середину O(n), дружит с кэшем процессора. list — двусвязный список: вставка и удаление по итератору O(1), доступа по индексу нет, каждый элемент — отдельная аллокация. На практике vector почти всегда быстрее даже на вставках.

Чем vector отличается от deque?

deque хранит данные блоками, а не одним куском: вставка в начало и конец O(1), доступ по индексу O(1), но память не сплошная. При добавлении в концы ссылки на элементы остаются действительными.

Чем map отличается от unordered_map?часто

map — сбалансированное дерево: операции O(log n), ключи хранятся по порядку, нужен оператор <. unordered_map — хэш-таблица: операции O(1) в среднем и O(n) в худшем, порядка нет, нужны хэш-функция и ==. По умолчанию берут unordered_map, map — когда нужен порядок или диапазоны.

Какими свойствами должен обладать ключ map и unordered_map?

Для map — строгий порядок через operator< (или свой компаратор). Для unordered_map — хэш-функция std::hash и сравнение на равенство; равные ключи обязаны давать равный хэш. Ключ не должен меняться, пока лежит в контейнере.

Что такое итератор и что такое его инвалидация?часто

Итератор — объект, указывающий на элемент контейнера, обобщение указателя. Инвалидация — итератор перестал быть действительным после изменения контейнера: у vector после перевыделения памяти или erase, у map — только у удалённого элемента. Использование такого итератора — неопределённое поведение.

Как удалить элементы из vector по условию?часто

Идиома erase-remove: v.erase(std::remove_if(v.begin(), v.end(), pred), v.end());. remove_if сдвигает оставляемые элементы в начало, erase отрезает хвост. В C++20 — std::erase_if(v, pred). В цикле: it = v.erase(it) вместо ++it.

Зачем нужен reserve?

Заранее выделить память под известное число элементов, чтобы push_back не перевыделял блок много раз. Не меняет size. resize меняет размер и создаёт элементы.

Чем emplace_back отличается от push_back?

push_back принимает готовый объект и копирует или перемещает его. emplace_back принимает аргументы конструктора и создаёт объект сразу на месте в контейнере.

Что вернёт map[key], если ключа нет?

Создаст элемент со значением по умолчанию и вернёт ссылку на него. Поэтому для проверки наличия используют find, count или contains (C++20), а at() бросает исключение на отсутствующем ключе.

Какая сложность у основных операций контейнеров?часто

vector: индекс O(1), push_back O(1) в среднем, вставка в середину O(n), поиск O(n). list: вставка по итератору O(1), поиск O(n). map/set: всё O(log n). unordered_map: O(1) в среднем. std::sort: O(n log n). Бинарный поиск: O(log n).

Что такое шаблоны?

Способ написать код один раз для разных типов: template <typename T> T max(T a, T b). Компилятор создаёт отдельную версию под каждый использованный тип (инстанцирование). Цена: код шаблонов лежит в заголовках, растут время сборки и размер программы.

Что такое специализация шаблона?

Отдельная реализация шаблона для конкретного типа: общий шаблон работает для всех, а для bool или const char* написана своя версия. Бывает полная и частичная (только у классов).

Какие алгоритмы STL используете чаще всего?

sort, find, find_if, count_if, transform, accumulate, any_of/all_of, min_element/max_element, remove_if, unique, lower_bound, copy. Они принимают пару итераторов и лямбду и почти всегда лучше ручного цикла.

Современный C++ 11

Какие стандарты C++ вы знаете и что в них появилось?часто

C++11 — auto, лямбды, перемещение, умные указатели, nullptr, цикл по диапазону, override, потоки. C++14 — обобщённые лямбды, make_unique. C++17 — optional, variant, any, string_view, структурные привязки, filesystem. C++20 — концепты, ranges, корутины, модули, span. C++23 — expected, print.

Что такое auto и какие у него подводные камни?часто

Вывод типа переменной компилятором, тип остаётся статическим. Голый auto отбрасывает ссылку и const, поэтому auto x = obj.name() делает копию. Нужна ссылка — auto& или const auto&.

Что такое лямбда-функция?часто

Безымянная функция, записанная на месте использования: [захват](параметры) { тело }. Компилятор превращает её в объект класса с operator(), где захваченные переменные — поля.

Как лямбда захватывает переменные?часто

[x] — по значению, копия на момент создания. [&x] — по ссылке. [=] и [&] — всё используемое по значению или по ссылке. [this] — указатель на объект. [p = std::move(ptr)] — захват с инициализацией. Опасность: ссылка на переменную, которая уничтожена к моменту вызова.

Чем std::function отличается от лямбды?

У каждой лямбды свой уникальный тип. std::function<R(Args)> — обёртка, которая хранит любую вызываемую сущность с подходящей сигнатурой: лямбду, функцию, функтор. Удобна для полей и колбэков, но медленнее и может выделять память.

Что такое std::optional?часто

Объект, который содержит значение типа T или пуст (std::nullopt). Заменяет «магические» значения вроде -1 и флаги. Проверка: if (opt), доступ: *opt, opt.value() (бросает, если пусто), opt.value_or(def).

Что такое std::variant и std::any?часто

variant<A, B> хранит значение одного из перечисленных типов и помнит, какого; доступ через std::get, std::get_if, std::visit. any хранит значение любого типа, достать можно только через any_cast с точным типом, иначе bad_any_cast. variant — когда варианты известны, any — последнее средство.

Что такое constexpr?

Пометка, что значение или функция могут быть вычислены при компиляции. Результат можно использовать как размер массива или параметр шаблона.

Что такое enum class?

Перечисление с областью видимости: значения пишутся как Color::Red, не превращаются в int неявно и не конфликтуют с другими именами.

Что такое структурные привязки?

Распаковка пары, кортежа или структуры в переменные: auto [key, value] = *it;, for (const auto& [k, v] : map). Аналог деструктуризации в JavaScript, C++17.

Что такое string_view и span?

Невладеющие «окна»: string_view — указатель и длина на чужую строку, span — на чужой массив. Передаются без копирования. Опасность одна: данные должны жить дольше окна.

Многопоточность 10

Чем процесс отличается от потока?часто

Процесс — запущенная программа со своим адресным пространством, изолированная от других. Поток — последовательность выполнения внутри процесса: потоки делят память и ресурсы процесса, у каждого свой стек. Создать поток дешевле, но общая память требует синхронизации.

Что такое состояние гонки?часто

Результат зависит от того, в каком порядке потоки выполнят свои операции. Гонка данных — два потока обращаются к одной переменной без синхронизации и хотя бы один пишет; в C++ это неопределённое поведение. Даже ++counter не атомарен: это чтение, прибавление и запись.

Что такое мьютекс?часто

Замок: пока один поток его держит, другие ждут на попытке захвата. Защищает участок кода, в котором меняются общие данные. В C++ — std::mutex, захватывают его не вручную, а через std::lock_guard или std::unique_lock (RAII), чтобы он освободился и при исключении.

Что такое взаимная блокировка (deadlock) и как её избежать?часто

Два потока ждут друг друга вечно: первый держит замок A и ждёт B, второй держит B и ждёт A. Способы избежать: всегда захватывать замки в одном порядке; захватывать оба сразу через std::scoped_lock; держать замок как можно короче и не вызывать под ним чужой код.

Что такое std::atomic?

Тип, операции над которым неделимы без мьютекса: std::atomic<int> counter; ++counter; безопасно из нескольких потоков. Годится для счётчиков и флагов, для составных операций над несколькими переменными нужен мьютекс.

Что такое условная переменная?

std::condition_variable позволяет потоку спать, пока другой не сообщит, что условие изменилось. Типичный случай — очередь задач: потребитель ждёт, производитель кладёт задачу и вызывает notify_one. Ожидание всегда с проверкой условия из-за ложных пробуждений: cv.wait(lock, [&] { return !queue.empty(); }).

Как запустить поток в C++?

std::thread t(func, args); затем обязательно t.join() (дождаться) или t.detach() (отпустить), иначе программа завершится аварийно. В C++20 — std::jthread, который сам делает join. Для получения результата — std::async и std::future.

Потокобезопасны ли контейнеры STL?

Нет. Одновременное чтение из нескольких потоков безопасно, но если хотя бы один поток пишет, доступ нужно защищать мьютексом самостоятельно.

Что значит потокобезопасный код?

Код, который корректно работает при одновременном вызове из нескольких потоков. Достигается отсутствием общего изменяемого состояния, синхронизацией или неизменяемыми данными.

Как организована работа с потоками в Qt?

Объект-работник переносят в поток через moveToThread, запускают сигналом, результат возвращают сигналом; соединения между потоками автоматически становятся Queued. Альтернатива — QtConcurrent::run с QFutureWatcher. Виджеты трогают только из главного потока.

Qt 18

Что такое сигналы и слоты?часто

Механизм связи объектов, реализация паттерна «наблюдатель». Объект испускает сигнал о событии, не зная получателей; слот — функция-обработчик; connect связывает их. К одному сигналу можно подключить много слотов, и наоборот.

Что такое moc и макрос Q_OBJECT?часто

В C++ нет сигналов, слотов и информации о типах во время выполнения. Q_OBJECT помечает класс, а moc (метаобъектный компилятор) перед сборкой генерирует для него файл с реализацией сигналов и метаинформацией. Без макроса сигналы, слоты и qobject_cast не работают.

Как Qt управляет памятью?часто

Через дерево объектов: у QObject есть родитель, и родитель в своём деструкторе удаляет всех детей. Поэтому new QPushButton(this) без delete корректно. Объект без родителя удаляешь сам или держишь на стеке. Отдавать объект и родителю, и умному указателю нельзя: будет двойное удаление.

Какие бывают типы соединений сигнал-слот?часто

Direct — слот вызывается сразу в потоке отправителя, как обычная функция. Queued — вызов ставится в очередь событий потока получателя, аргументы копируются. Auto (по умолчанию) — Direct в одном потоке и Queued между разными. Ещё BlockingQueued (ждёт выполнения) и Unique.

Что такое цикл событий?часто

Бесконечный цикл внутри app.exec(): берёт события из очереди (мышь, клавиатура, таймеры, сетевые данные, отложенные вызовы слотов) и рассылает их объектам. Пока обработчик не вернул управление, следующее событие не обрабатывается, поэтому долгая работа в главном потоке замораживает окно.

Почему нельзя обновлять интерфейс из другого потока?часто

Виджеты не потокобезопасны и принадлежат главному потоку. Из фонового потока результат передают сигналом: соединение между потоками станет Queued, и слот выполнится в главном потоке.

Как выполнить долгую операцию, не заморозив окно?часто

Вынести её в другой поток: объект-работник плюс moveToThread, или QtConcurrent::run с QFutureWatcher. Прогресс и результат возвращать сигналами. Вызов processEvents() внутри расчёта — плохой обходной путь.

Чем старый синтаксис connect отличается от нового?

Старый — SIGNAL(clicked()) и SLOT(onClick()): имена сравниваются как строки при выполнении, ошибка видна только в консоли. Новый — указатели на методы: &QPushButton::clicked, проверяется компилятором, можно подключать лямбды.

Что такое deleteLater?

Отложенное удаление QObject: объект удалится, когда управление вернётся в цикл событий. Нужен, когда объект нельзя удалить прямо сейчас, например внутри обработчика его собственного сигнала.

Чем событие отличается от сигнала?

Событие приходит от системы или из очереди конкретному объекту и обрабатывается переопределением виртуального метода (mousePressEvent, paintEvent). Сигнал испускает сам объект, и его получают все подключённые слоты.

Что такое Model/View?

Разделение данных и отображения. Модель (QAbstractItemModel и наследники) знает, сколько элементов и что в каждом; представление (QTableView, QListView) запрашивает только видимое и рисует; делегат отвечает за отрисовку и редактирование ячейки. Одна модель может иметь несколько представлений.

Что такое компоновки и зачем они нужны?

Объекты, которые сами расставляют дочерние виджеты и пересчитывают размеры при изменении окна: QVBoxLayout, QHBoxLayout, QGridLayout, QFormLayout. Избавляют от ручных координат и делают интерфейс устойчивым к шрифтам и масштабу экрана.

Чем QString отличается от std::string?

QString хранит текст в UTF-16 и знает про Юникод: корректно работает с кириллицей, регистром, переводами. std::string — последовательность байтов без кодировки. У QString есть неявное разделение данных: копия дешёвая до первого изменения.

Что такое неявное разделение данных (implicit sharing)?

Копия объекта (QString, QVector, QImage) не копирует данные, а разделяет их с оригиналом по счётчику ссылок. Настоящая копия делается только при попытке изменить. Поэтому такие объекты дёшево передавать по значению.

Что такое QVariant?

Контейнер, который может хранить значение любого зарегистрированного типа: число, строку, цвет, свой тип. На нём построены модели, свойства и QSettings.

Чем Qt Widgets отличается от QML?

Widgets — классические элементы интерфейса на C++, стандарт для настольных инженерных программ. QML — декларативный язык описания интерфейса с JavaScript и отрисовкой на видеокарте, удобен для анимаций и нестандартного вида. Логика в обоих случаях на C++.

Чем Qt 5 отличается от Qt 6?

Qt 6 требует C++17, основная сборка — CMake вместо qmake, QVector объединён с QList, убраны QRegExp и QTextCodec, графика идёт через прослойку RHI, масштабирование на экранах высокой плотности включено всегда. Сигналы и слоты, дерево объектов и виджеты остались прежними.

Что такое Q_PROPERTY?

Объявление свойства с функцией чтения, записи и сигналом об изменении. Свойство доступно по имени во время выполнения: его используют QML, Qt Designer, анимации и таблицы стилей.

Алгоритмы и структуры данных 15

Что такое сложность алгоритма и O-нотация?часто

Оценка того, как растёт время или память с ростом размера входа. O(1) — не зависит, O(log n) — бинарный поиск, O(n) — один проход, O(n log n) — хорошие сортировки, O(n²) — вложенные циклы. Константы и младшие слагаемые отбрасывают.

Как работает бинарный поиск?часто

На отсортированном массиве сравниваем искомое с серединой и отбрасываем половину, в которой его быть не может. O(log n). Середину считают как lo + (hi - lo) / 2, чтобы не было переполнения.

Какие сортировки вы знаете и какая у них сложность?часто

Пузырьком, выбором, вставками — O(n²). Слиянием — O(n log n) всегда, стабильна, требует O(n) памяти. Быстрая — O(n log n) в среднем, O(n²) в худшем, на месте. Пирамидальная — O(n log n), на месте. std::sort — гибрид (introsort), гарантированно O(n log n).

Как работает быстрая сортировка?часто

Выбирают опорный элемент, переставляют массив так, чтобы меньшие оказались слева от него, а большие справа, и рекурсивно сортируют обе части. Худший случай O(n²) — когда опорный каждый раз оказывается крайним; лечится выбором середины или случайного элемента.

Что такое стабильная сортировка?

Сортировка, которая сохраняет исходный порядок равных элементов. Важно при сортировке по нескольким полям по очереди. Стабильны слиянием и вставками, std::stable_sort; нестабильны быстрая и std::sort.

Как устроена хэш-таблица?часто

Массив корзин. Хэш-функция превращает ключ в число, по нему выбирается корзина. Когда два ключа попадают в одну корзину (коллизия), их хранят списком или ищут следующую свободную ячейку. В среднем операции O(1); когда таблица заполняется, она увеличивается и пересчитывает положение всех ключей.

Чем массив отличается от связного списка?часто

Массив — сплошная память: доступ по индексу O(1), вставка в середину O(n). Список — узлы со ссылками: доступ к k-му элементу O(n), вставка по известному месту O(1). Массив намного быстрее на практике из-за кэша процессора.

Что такое стек и очередь?часто

Стек — последним пришёл, первым вышел (LIFO): вызовы функций, отмена действий, проверка скобок. Очередь — первым пришёл, первым вышел (FIFO): задачи на обработку, обход в ширину.

Что такое двоичное дерево поиска?

Дерево, где у каждого узла слева лежат меньшие ключи, справа большие. Поиск, вставка и удаление — O(высота). В сбалансированном дереве (красно-чёрное, AVL) высота O(log n); несбалансированное может выродиться в список с O(n).

Что такое куча (heap) как структура данных?

Двоичное дерево в массиве, где родитель не меньше детей. Максимум доступен за O(1), вставка и извлечение — O(log n). На ней работают std::priority_queue и пирамидальная сортировка.

Что такое рекурсия и чем она опасна?

Функция вызывает сама себя; нужны базовый случай и шаг к нему. Каждый вызов занимает место на стеке, слишком глубокая рекурсия приводит к переполнению стека. Любую рекурсию можно переписать циклом с явным стеком.

Чем обход в глубину отличается от обхода в ширину?

В глубину (DFS) идём по одной ветке до конца, потом возвращаемся; реализуется рекурсией или стеком. В ширину (BFS) обходим по уровням через очередь; находит кратчайший путь по числу рёбер.

Как развернуть строку или массив на месте?часто

Два указателя с концов навстречу: меняем элементы местами и сдвигаем указатели, пока не встретятся. O(n) времени, O(1) памяти.

Как найти дубликаты в массиве?

Три варианта: сравнить все пары — O(n²); отсортировать и сравнить соседей — O(n log n); складывать в хэш-множество и проверять наличие — O(n) времени и O(n) памяти.

Как развернуть односвязный список?

Идти по списку с тремя указателями: предыдущий, текущий, следующий. На каждом шаге запомнить следующий, развернуть ссылку текущего назад и сдвинуться. O(n) времени, O(1) памяти.

Статистика 5

Что такое среднее, медиана и мода?часто

Среднее — сумма, делённая на количество. Медиана — значение посередине отсортированного набора; при чётном количестве — среднее двух центральных. Мода — самое частое значение. Для 2, 3, 3, 5, 100: среднее 22,6, медиана 3, мода 3.

Когда медиана лучше среднего?часто

Когда в данных есть выбросы или распределение перекошено: зарплаты, время ответа, сигнал с импульсными помехами. Одно аномальное значение сильно сдвигает среднее и почти не влияет на медиану.

Как посчитать медиану массива и какая у этого сложность?часто

Отсортировать и взять центральный элемент — O(n log n). Быстрее — std::nth_element: ставит на нужную позицию правильный элемент в среднем за O(n), не сортируя остальное.

Как найти моду?

Подсчитать частоты в хэш-таблице и взять ключ с наибольшим счётчиком: O(n) времени и памяти. Без памяти — отсортировать и найти самую длинную серию одинаковых. Мод может быть несколько.

Что такое дисперсия и стандартное отклонение?

Дисперсия — среднее квадратов отклонений значений от среднего. Стандартное отклонение — корень из дисперсии: показывает типичный разброс в тех же единицах, что и данные.

Сеть 8

Чем TCP отличается от UDP?часто

TCP устанавливает соединение, гарантирует доставку, порядок и отсутствие дубликатов, управляет скоростью; для программы это поток байтов. UDP без соединения и гарантий: быстрее, сохраняет границы сообщений (датаграммы), умеет рассылку многим. TCP — команды, файлы, HTTP; UDP — звук, видео, телеметрия, DNS.

Как устанавливается TCP-соединение?часто

Тройное рукопожатие: клиент шлёт SYN, сервер отвечает SYN-ACK, клиент подтверждает ACK. Стороны обмениваются начальными номерами последовательности.

Как TCP обеспечивает надёжность?часто

Нумерует байты, получатель подтверждает принятое (ACK), неподтверждённое отправляется повторно. По номерам восстанавливается порядок и отбрасываются дубликаты. Контрольная сумма выявляет повреждения. Окно получателя ограничивает поток, алгоритм перегрузки снижает скорость при потерях.

Что такое сокет и порт?

Порт — число от 0 до 65535, по которому ОС определяет, какой программе отдать пришедшие данные. Сокет — конечная точка соединения (адрес плюс порт) и объект в программе, через который идёт обмен.

Почему при чтении из TCP-сокета можно получить полсообщения?

TCP — поток байтов без границ сообщений: одно отправленное сообщение может прийти частями, а два — склеиться. Границы обозначает сама программа: длиной перед сообщением или разделителем.

Что такое модель OSI или стек TCP/IP?

Разделение сети на уровни. В стеке TCP/IP их четыре: канальный (Ethernet, Wi-Fi), сетевой (IP — доставка между узлами по адресу), транспортный (TCP, UDP — доставка между программами по порту), прикладной (HTTP, DNS, SSH). В модели OSI уровней семь.

Что такое IP-адрес, маска подсети и DNS?

IP-адрес — номер узла в сети. Маска показывает, какая часть адреса — номер сети, а какая — номер узла: 192.168.1.0/24 — сеть на 254 узла. DNS переводит имя (example.com) в IP-адрес.

Что такое порядок байтов (endianness)?

Порядок, в котором байты многобайтового числа лежат в памяти. Big-endian — старший первым, так принято в сетевых протоколах. Little-endian — младший первым, так на x86. При передаче чисел по сети их приводят к сетевому порядку: htonl, qToBigEndian.

Сборка, ОС, инструменты 8

Из каких этапов состоит сборка программы на C++?часто

Препроцессор раскрывает #include и макросы. Компилятор превращает каждый .cpp в объектный файл. Компоновщик (линковщик) соединяет объектные файлы и библиотеки в исполняемый файл и связывает вызовы с определениями.

Чем статическая библиотека отличается от динамической?часто

Статическая (.a, .lib) встраивается в исполняемый файл при сборке: файл больше, зависимостей нет. Динамическая (.so, .dll) загружается при запуске: файл меньше, библиотеку можно обновить отдельно и делить между программами, но она должна быть на машине пользователя.

Что означает ошибка undefined reference или unresolved external symbol?

Ошибка компоновщика: функция объявлена и вызывается, но определение не найдено. Причины: не подключена библиотека, файл не добавлен в сборку, объявление не совпадает с определением, для класса с Q_OBJECT не отработал moc.

Что такое CMake и qmake?

Генераторы сборки: по описанию проекта (CMakeLists.txt, .pro) создают инструкции для настоящего сборщика — Makefile, Ninja, проект Visual Studio. Нужны, чтобы один проект собирался разными компиляторами на разных системах.

На что обращать внимание в кроссплатформенном коде?

Размеры типов (long — 32 бита на Windows и 64 на Linux, брать int32_t/int64_t), регистр в именах файлов, разделители путей, конец строки, экспорт символов из DLL, различия компиляторов. Системные вызовы прячут за Qt, Boost или #ifdef.

Как отлаживаете программу на C++?

Отладчик (gdb, Visual Studio, отладчик Qt Creator): точки останова, просмотр переменных, стек вызовов. Журналирование. Для ошибок памяти — AddressSanitizer и valgrind. Для падений — разбор дампа и стека.

Что такое Git и какие команды используете?

Система контроля версий. Повседневное: clone, status, add, commit, push, pull, branch, checkout/switch, merge, rebase, log, diff, stash. Работа ветками с запросом на слияние и ревью.

Чем merge отличается от rebase?

merge соединяет ветки отдельным коммитом слияния и сохраняет историю как была. rebase переносит твои коммиты поверх свежей версии целевой ветки: история линейная, но коммиты переписываются, поэтому общие ветки так не трогают.

Python 10

Чем Python отличается от C++?часто

Python интерпретируется, типы динамические, памятью управляет сам (подсчёт ссылок и сборщик циклов), код короче и пишется быстрее, но выполняется во много раз медленнее. C++ компилируется, типы статические, память под контролем программиста. Python берут для моделей, прототипов и тестов, C++ — для рабочего кода.

Что такое GIL?часто

Глобальная блокировка интерпретатора: в один момент байт-код Python выполняет только один поток. Потоки помогают при ожидании ввода-вывода, но не ускоряют вычисления. Для вычислений берут numpy, несколько процессов или выносят код в C++.

Чем список отличается от кортежа?часто

Список (list) изменяемый, кортеж (tuple) нет. Поэтому кортеж может быть ключом словаря и элементом множества, а список не может.

Какие типы изменяемые, а какие нет?

Неизменяемые: int, float, str, tuple, bool, frozenset. Изменяемые: list, dict, set. Переменная хранит ссылку, поэтому b = a для списка не создаёт копию.

Чем опасен изменяемый аргумент по умолчанию?часто

Значение по умолчанию создаётся один раз при определении функции. def f(x, items=[]) копит элементы между вызовами. Правильно: items=None и создание списка внутри функции.

Что такое декоратор?

Функция, которая принимает функцию и возвращает новую, обычно обёртку с дополнительным поведением: журналирование, замер времени, кэш. Запись @decorator над функцией — сокращение для f = decorator(f).

Что такое генератор?

Функция с yield: возвращает значения по одному и сохраняет состояние между вызовами. Не держит всю последовательность в памяти. Генераторное выражение — (x * 2 for x in data).

Чем == отличается от is?

== сравнивает значения, is — что это один и тот же объект в памяти. Для None пишут x is None.

Что такое numpy и почему он быстрый?

Библиотека массивов: данные одного типа лежат сплошным блоком, а операции над всем массивом выполняет скомпилированный код на C, без цикла Python. Запись a * 2 + b считается для всех элементов сразу — это называют векторизацией.

Что такое with?

Менеджер контекста: гарантирует освобождение ресурса при выходе из блока, в том числе по исключению. with open(path) as f: закроет файл сам. Аналог RAII в C++.

Boost 4

Что такое Boost?

Набор открытых рецензируемых библиотек для C++. Многое из стандарта сначала появилось там: умные указатели, thread, function, regex (C++11), optional, variant, any, filesystem (C++17).

Какие библиотеки Boost знаете?

Asio — сеть и асинхронный ввод-вывод. Beast — HTTP и WebSocket. program_options — аргументы командной строки. Test — модульные тесты. Algorithm/string — split, trim, join. lexical_cast — строка в число и обратно. Signals2 — сигналы и слоты без Qt. Filesystem, Optional, Variant — для стандартов до C++17.

Что такое Boost.Asio и io_context?

Библиотека асинхронного ввода-вывода. io_context — цикл событий: запускаешь асинхронную операцию с обработчиком, а run() вызывает обработчики по мере готовности. Та же модель, что цикл событий в Qt и Node.js.

Когда брать Boost, а когда стандартную библиотеку?

Если нужное есть в std для стандарта проекта — брать std. Boost — для того, чего в стандарте нет (сеть, разбор аргументов) или нет в используемой версии: на C++14 вместо std::optional берут boost::optional.

Ничего не найдено. Измени запрос или фильтр.
